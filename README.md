# Cauliflower AI — Streamlit demo

## Files required
Place these three files in the same GitHub repository:
- `app.py`
- `requirements.txt`
- `cauliflower_model.keras` (download from Google Drive)
- `classes.json` (download from Google Drive)

## Deploy
1. Create a GitHub repository and upload the files above.
2. Open https://share.streamlit.io/ and sign in with GitHub.
3. Choose **Create app**, select your repository, branch, and `app.py`.
4. Deploy. Streamlit will provide a public URL you can share with your teacher.

Note: Hosting services may have memory/resource limits. If TensorFlow fails to install or the app exceeds resources, tell me the exact error so we can adjust.
